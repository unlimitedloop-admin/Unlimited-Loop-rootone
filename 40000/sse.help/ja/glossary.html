$07 / GLOSSARY

用語集

Ver.1.10

エディタ内やドキュメントで使われる用語をまとめています。

基本構造

プロジェクト（.sseproj）

複数のステージをまとめて管理する、エディタの最上位単位。実データは持たず、各ステージファイルへの参照とブックマーク一覧を保持する。

ステージ（.ssestage）

1つの面（ワールド）に相当する単位。複数のページで構成される。

ページ

画面1枚分（16×15タイル）に相当する編集単位。ゲーム内の「部屋」に対応する。

タイル

マップを構成する最小単位の画像パーツ（16×16 px）。

TileMap

ページ内のタイル配置情報。

ノード関連

ノード

ページの配置座標・接続関係を表す情報。Page Node Editor 上で編集する。

RoomId

ページに割り当てられる部屋番号。.bin のページヘッダで参照される。

Z座標

3D的な奥行きではなく、階層切り替えによるページ配置管理のための補助的な値。

編集補助機能

タグ

ステージやページに付与する分類・状態情報（例：TODO, WIP, BOSS）。プロジェクト単位で定義を管理する。（→ タグ）

ブックマーク

任意のページへ素早く移動するための目印。プロジェクト全体で一意に管理され、保存される。（→ ブックマーク）

マーカー

タイル単位の一時的な視覚目印。デバッグや動線確認に使用し、ファイルには保存されない。（→ マーカー）

メタタイル

複数タイルを組み合わせたプリセットタイル。繰り返し使うパターンをまとめて配置できる。ステージごとに保存される。（→ メタタイル）

オブジェクト関連

オブジェクト（エンティティ）

マップ上にタイルとは別に配置する敵などのこと。.def の entities として出力される。位置は部屋内のピクセル座標で、足元の中心を指す。

kind

オブジェクトの種類を表す値。ゲーム側の敵定義の id（例：metall）を指定する。

画像シート

オブジェクトの表示に使う画像。同じ大きさのコマに分割して使い、分割の仕方は同名の .json（分割定義）から読み込む。

テンプレート

画像シートの1コマと、kind などの既定値を組にしたもの。Object Palette で選んでマップに配置する。プロジェクト全体で共有する。

敵定義

ゲーム側で敵ごとの性能や見た目を定めた JSON ファイル（assets/data/enemies）。エディタは kind・カラーパターンの候補を得るために読み込む。

カラーパターン（パレットプリセット）

敵定義の palette_presets で定めた色替えの種類（例：default / yellow / blue / red）。オブジェクトの Palette で選ぶ。

プレイヤー開始位置

ステージ開始時にプレイヤーが立つ位置。.def の stage.start として出力される。

リスポーン

部屋に入り直したときに敵が再び出現するかどうかの設定（always / until_defeated / once）。部屋ごとの既定値と、オブジェクトごとの指定がある。

ファイル・出力関連

.bin

ゲーム実行用の描画専用バイナリファイル。タイル配置とページヘッダのみを保持する。

.def

ノード配置・タイル属性・エンティティ・イベントなど、ゲームロジックに関する定義データ（JSON）。

ページヘッダ

.bin の各ページ先頭16byteに格納される、部屋番号・隣接情報・スクロール種別などのメタ情報。
