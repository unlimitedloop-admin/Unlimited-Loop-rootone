$02 / BASICS

基本的な使い方

Ver.1.10

プロジェクトの作成からステージの出力までの、基本的な作業の流れを説明します。

全体の流れ

プロジェクト作成 / 読み込み
  ↓
タイルセット読み込み
  ↓
ステージ作成
  ↓
マップ編集（タイル配置）
  ↓
オブジェクト配置（敵・プレイヤー開始位置）
  ↓
ページ接続の設定（ノードエディタ）
  ↓
プロジェクト保存
  ↓
BIN 出力（ゲームアプリへ）

1. プロジェクトを作成する

File > New Project（Ctrl+P）から新規プロジェクトを作成します。 プロジェクトファイル（.sseproj）は、複数のステージファイル（.ssestage）への 参照を管理する、プロジェクト全体の管理ファイルです。

2. タイルセットを読み込む

File > Import TileSet からタイル画像（PNG / BMP）を読み込みます。 読み込んだ画像は 16×16 px 単位で分割され、タイルパレットに一覧表示されます。

3. ステージを作成する

File > New Stage（Ctrl+N）で新しいステージを追加します。 1つのステージは複数のページ（部屋）で構成され、1ページは 16×15 タイル（256×240 px）です。

4. マップを編集する

タイルパレットから配置したいタイルを選択し、マップビュー上でクリックまたはドラッグして配置します。

操作内容
左クリック / ドラッグタイル配置
右クリック または Alt+クリックタイル取得（スポイト）
Shift+クリック塗りつぶし
Deleteタイル削除

詳しい操作方法は「コマンドリファレンス」を参照してください。

5. オブジェクト（敵）を配置する

マップには、タイルとは別に敵などのオブジェクトとプレイヤーの開始位置を配置できます。 配置した内容は .def の entities / stage.start として出力されます。

5-1. 画像シートを登録する

Object Palette（Ctrl+F9）を開き、＋ボタンから敵の画像（PNG）を追加します。 画像と同じ名前の .json（分割定義）があれば自動で読み込み、コマ単位に分割して表示します。 自動で読み込みたくない場合は、Tools > Options... の Object タブで設定を変更できます。

5-2. テンプレートを登録する

シートのコマを選び、「選択したコマをテンプレート登録...」から kind（敵定義の id）などの既定値を設定します。 テンプレートはプロジェクト全体で共有され、配置するときはこのテンプレートを選びます。 テンプレートの右クリックメニューから、編集・削除ができます。

5-3. マップに配置する

オブジェクトツール（O）に切り替え、テンプレートを選んでマップ上をクリックします。 位置はオブジェクトの足元の中心で指定し、スナップ（1 / 8 / 16 px）で揃えることもできます。

操作内容
左クリック（何もない所）選択中のテンプレートを配置
左クリック（オブジェクト上）＋ドラッグ選択・移動
右クリック（オブジェクト上）削除
矢印キー / Shift+矢印キー選択中のオブジェクトを 1px / 8px 移動
Delete選択中のオブジェクトを削除
Esc選択解除

選択したオブジェクトの ID・Kind・Palette・向き・リスポーンなどは、Properties ウィンドウの Entity 欄で変更できます。 部屋ごとのリスポーンの既定値はページの「Enemy Respawn」で設定します。

5-4. プレイヤー開始位置を置く

Object Palette の「プレイヤー開始位置を置く」を ON にしてマップをクリックすると、開始位置（START）を設定できます。 開始位置の上で右クリックすると解除できます。

5-5. 敵定義とカラーパターン（任意）

Object Palette の ⚙ ボタンから、ゲーム側の敵定義フォルダ（assets/data/enemies）と NES パレット（assets/system/nes_palette.txt）を指定すると、次のことができるようになります。

  • Kind・Palette を候補から選ぶ
  • 敵定義のカラーパターン（palette_presets）で色を替えて表示する
  • .def の出力時に、敵定義に無い kind（ゲーム内で出現しない敵）をエラーとして知らせる

敵定義を書き換えたときは、⚙ ボタンから OK を押すと読み込み直します。

5-6. オブジェクトを探す・まとめて削除する

Object List（Ctrl+F10）では、ステージ内のオブジェクトを ID・kind・Palette で絞り込んで一覧できます。 一覧の行をダブルクリック（または Enter）すると、そのオブジェクトの位置へ移動します。 オブジェクトツール使用中は F4 / Shift+F4 で次・前の結果へ移動できます。

一覧で選んだもの（Delete）や、絞り込んだ結果をまとめて削除することもできます。 Stage Explorer のステージ・ページの右クリックメニューからは、そのステージ・ページのオブジェクトをすべて削除できます。 いずれも Undo（Ctrl+Z）で元に戻せます。

6. ページ同士を接続する

Page Node Editor（F11）を開くと、ページ同士の接続関係を視覚的に編集できます。 設定済みのページの上下左右に自動で候補位置が表示されるので、右クリックメニューから 新規ページを作成・接続していきます。

7. 保存する

File > Save Project（Ctrl+Shift+S）でプロジェクト全体を保存します。 現在編集中のステージのみ保存したい場合は File > Save Stage（Ctrl+S）を使用します。

8. ゲームアプリ用データを出力する

File > Export BIN で現在のステージを、File > Export All Stages で すべてのステージをバイナリファイル（.bin）として出力します。同じ場所に、同じ名前の ステージ定義（.def）も出力されます。出力されたデータはゲームプログラム側から読み込んで使用します。

出力の前に、オブジェクトの配置内容が確認されます。ゲーム側で読み込めない内容（ID の重複、 RoomId が未割当の部屋への配置、敵定義に無い kind など）がある場合は、一覧を表示して出力を中止します。 敵定義に無い Palette など、出力はできるものの意図と違いそうな内容は、確認のうえで出力できます。

便利な使い方：タイルを探す

マップ上で右クリックし「このタイル（XX）を検索...」を選ぶと、そのタイル番号を入れた状態で タイル検索ダイアログが開きます。タイル検索・置換ダイアログを開いている間は、タイルパレットで タイルを選ぶと、最後に入力していた欄にその番号が入ります。 見つからなかった場合は、ダイアログ内に「見つかりません」と表示されます。
