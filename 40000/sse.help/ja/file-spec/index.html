$05 / FILE SPECIFICATION

インターフェースファイル仕様

Ver.1.10

本エディタとゲームアプリの間でやり取りされるファイルの構成と役割について説明します。 詳細な内部スキーマは各設計書（BD-005〜BD-007）を参照してください。

ファイル構成

ファイル拡張子役割
プロジェクトファイル.sseprojエディタ専用のプロジェクト管理データ
ステージファイル.ssestageステージ本体（TileMap・ページ情報等）
マップデータ.binゲーム実行用の描画専用バイナリ
ステージ定義.defゲームロジック定義（ノード配置・属性・イベント等）
タイル画像.png / .bmpタイルパレット画像
エディタ設定SSE_Config.iniエディタの表示状態・オプション設定（エディタ本体と同じフォルダ）

参照のみ行うファイル（Ver.1.10〜）

オブジェクトの配置で使います。エディタからは読み込むだけで、書き換えません。

ファイル例用途
画像シート*.pngオブジェクトの表示に使う画像（コマ単位に分割）
画像シートの分割定義*.jsonコマの大きさ・並び（{"Loader":{"tileWidth":32,"tileHeight":32,"tilesX":4,"tilesY":6}}）
敵定義（ゲーム側）assets/data/enemies/*.jsonKind の候補・カラーパターン（palette_presets）
NES パレット（ゲーム側）assets/system/nes_palette.txtカラーパターンの色替え表示

データの責務分離

本エディタは「編集用データ」「ゲーム実行用データ」を明確に分離して管理します。

ファイル責務
.sseproj / .ssestageエディタの正規データ（唯一の編集対象）
.binマップ構造の派生データ（常に再生成可能）
.defゲームロジック定義データ

.sseproj（プロジェクトファイル）

複数のステージへの参照（StageFilePath）と、プロジェクト全体で共有する情報 （ブックマーク・タグ・画像シート・テンプレート・敵定義の参照先）を保持します。 ステージの実データそのものは保持しません。 

Project.sseproj
 ├ BaseDirectory
 │   ├ Stage001.ssestage
 │   ├ Stage002.ssestage
 │   └ Stage003.ssestage
 ├ Bookmarks / Tags
 ├ SpriteSheets       … 画像シート（画像・分割定義のパスと分割値）
 ├ EntityTemplates    … 配置テンプレート（シートのコマ＋既定の Kind など）
 ├ EnemyDefinitionDirectory … 敵定義フォルダ
 └ NesPalettePath     … NES パレット

.ssestage（ステージファイル）

ステージ単位の TileMap・ページ情報・タグ割り当てなど、編集内容の実データを保持します。 Ver.1.10 で、オブジェクト配置に関する次の項目を追加しました。

項目内容.def での出力先
PlayerStartプレイヤー開始位置（ページと足元中心の座標）stage.start
Pages[].EnemyRespawn部屋ごとの敵リスポーンの既定値nodes[].enemyRespawn
Pages[].Entities部屋に配置したオブジェクト（ID・座標・Kind・Palette など）entities[]

これらの項目が無い以前のバージョンのファイルも、そのまま読み込めます。

.bin（マップデータ）

描画専用の固定長バイナリデータです。1ページあたり 0x100 byte で構成され、 先頭 16 byte がページヘッダ、残り 240 byte がタイルデータです。

アドレス項目内容
$00MagicStart固定値 0xA5（ヘッダ識別）
$01RoomId自分自身の部屋番号
$02〜$07隣接部屋番号左・右・上・下・手前・奥（未接続は 0xFF）
$08〜$0Bスクロール種別左・右・上・下（0:None / 1:Free / 2:Page / 3:Auto / 4:ObjectFollow / 5:EventDriven / 6:Loop）
$0CZZ座標（階層）
$0DFlags演出・状態フラグ（bit単位）
$0FMagicEnd固定値 0x5A（ヘッダ終端）

.def（ステージ定義データ）

ノード（配置座標）、タイル属性、エンティティ、イベントなど、ゲームロジックに関わる 情報を JSON 形式で保持します。人間可読で拡張性の高いデータです。 

{
  "version": "1.0",
  "stage": {},
  "nodes": [],
  "tileAttributes": {},
  "entities": [],
  "events": [],
  "triggers": [],
  "scripts": []
}

エンティティ（entities）

マップに配置したオブジェクトは、1体ずつ次の形式で出力されます。 

{
  "type": "enemy",
  "id": "metall_1",
  "roomId": 0,
  "position": { "x": 224, "y": 193 },
  "properties": {
    "kind": "metall",
    "palette": "default",
    "facing": "left",
    "respawn": "until_defeated",
    "despawnOffscreen": false
  }
}
項目内容
idステージ内で一意の識別子
roomId配置したページの RoomId
position部屋内のピクセル座標（X 0〜255、Y 0〜239）。足元の中心を指します
properties.kind敵定義の id（必須）
properties.palette ほかカラーパターン・向き・リスポーン・画面外で消えるか。未設定の項目は出力せず、ゲーム側の既定値になります

出力前に内容が確認され、ゲーム側で読み込めない内容があると出力を中止します（「基本的な使い方」の 8 を参照）。

設計方針
.def が唯一の正規データであり、.bin は常に .def から 再生成可能な派生データとして扱います。
