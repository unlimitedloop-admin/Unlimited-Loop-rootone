メタタイル

Ver.1.10

メタタイルは、複数のタイルを組み合わせて1つにまとめたものです。 足場や壁など、同じ形で何度も使うタイルの組み合わせを登録しておくと、1回のクリックで配置できます。

メタタイルを作る

Window > MetaTile Editor（F12）を開きます。 メタタイルパレットの右クリックメニュー「メタタイルエディタを起動...」からも開けます。

画面は次の3つの領域に分かれています。

領域内容
Tile Paletteステージのタイルセット。クリックで置くタイルを選びます
Edit Canvasメタタイルを描く場所
Previewできあがりの確認。Ctrl+マウスホイールで拡大・縮小します

Edit Canvas での操作：

操作内容
左クリック / 左ドラッグ選んだタイルを置く
右クリック / 右ドラッグタイルを消す（空きマスにする）
中クリックそのマスのタイルを選ぶ（スポイト）
Ctrl+Z / Ctrl+Y元に戻す / やり直し

上部のツールバー：

項目内容
Saved保存済みのメタタイルを選んで、編集し直す
Nameメタタイルの名前
Size大きさ（2×2 / 4×4 / 8×8 / 1×4 / 4×1）
New新しいメタタイルを作り始める
Save保存する（編集し直している場合は上書き）
Save As別のメタタイルとして新しく保存する
Delete選んでいるメタタイルを削除する（確認あり）
Clearキャンバスを空にする

メタタイルを配置する

メタタイルパレット（Stage Explorer の下）で、保存したメタタイルを選びます。 マウスを乗せると ID・名前・大きさが表示されます。 マップ上をクリックすると、その位置を左上としてメタタイルが置かれます。ドラッグすると続けて置けます。

  • 空きマスの部分は配置されず、元のタイルがそのまま残ります
  • ドラッグで続けて置いた分は、まとめて1回の Undo で元に戻せます
  • Alt を押している間はメタタイルを置かず、スポイト（タイルの取得）になります
  • タイルパレットで普通のタイルを選ぶと、メタタイルの選択は解除されます
  • オブジェクトツール使用中は、メタタイルは置かれません

保存

メタタイルはステージごとに、各 .ssestage に保存されます。 別のステージで使う場合は、そのステージで作り直してください。 MetaTile Editor で保存・削除した内容は、ステージの未保存の変更として扱われるので、Save Stage / Save Project で保存してください。
