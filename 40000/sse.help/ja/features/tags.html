$03.1 / TAGS

タグ

Ver.1.10

タグは、ステージやページに付ける分類・状態の印です。「TODO」「WIP」「BOSS」のように、 作業の進み具合や内容をひと目で分かるようにできます。

タグを作る

Window > Tag Manager（Ctrl+F7）を開きます。タグはプロジェクト全体で共有され、 どのステージ・ページにも付けられます。

項目内容
Labelタグの名前
Colorタグの色。「変更...」から選びます
Iconタグのアイコン。「選択...」から、用意されたアイコンか任意の画像を選びます。「クリア」でアイコンなしにします
Priority優先度（0〜999）。値が小さいほど優先されます（表示の順番と代表タグの決定に使います）
  • New：新しいタグの入力を始めます
  • Save：入力内容を保存します（一覧で選んだタグを編集中なら、そのタグを更新します）
  • Delete：選んだタグを削除します。付けていたすべてのステージ・ページからも外れます

アイコンに選んだ画像は、プロジェクトフォルダの TagIcons フォルダにコピーされて使われます。

タグを付ける・外す

Properties ウィンドウ（F8）の Stage 欄または Page 欄にある「Tags」の「編集...」を押すと、 タグの一覧がチェックボックスで表示されます。付けたいタグにチェックを入れて OK を押します。 チェックを外せば、そのタグは外れます。この操作は Undo（Ctrl+Z）で元に戻せます。

タグの表示

場所表示
Properties ウィンドウ付いているタグが、色とアイコン付きのバッジで並びます（Priority の順）
Stage Explorerステージ・ページ名の文字色が、代表タグの色になります
Page Node Editor選んだページの情報欄に、付いているタグの名前が表示されます
代表タグ
複数のタグが付いている場合、Priority の値が最も小さいタグ（同じ値なら名前順で先のもの）が代表になります。 文字色は、背景に対して読みやすいように明るさが補正されます。

保存

タグの定義（名前・色・アイコン・優先度）は .sseproj に、どのステージ・ページに付けたかは 各 .ssestage に保存されます。Tag Manager での変更もプロジェクトの未保存の変更として扱われるので、 Save Project で保存してください。
