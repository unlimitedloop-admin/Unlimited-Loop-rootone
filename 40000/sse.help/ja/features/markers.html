$03.3 / MARKERS

マーカー

Ver.1.10

マーカーは、タイルに付ける一時的な目印です。あとで直したい場所や、プレイヤーの動線の確認などに使います。 マップのデータは変わらず、ファイルにも保存されません。

マーカーを付ける・消す

マーカーツール（K / Ctrl+4、ツールバーのマーカーボタン）に切り替えて、マップ上を操作します。 マーカーツールに切り替えると、マーカーの表示（Marker Overlay）が自動的に ON になります。

操作内容
左クリックマーカーを付ける（すでにあれば消す）
左ドラッグなぞった場所に続けて付ける（すでにある所はそのまま）
右クリックマーカーを消す

マーカーをたどる

操作内容
Ctrl+M次のマーカーへ移動
Ctrl+Shift+M前のマーカーへ移動

マーカーは付けた順にたどります。別のページにあるマーカーへは、ページを切り替えて移動します。 最後のマーカーの次は最初のマーカーに戻ります。現在のマーカーは枠線で囲んで表示されます。

表示と色

  • View > Marker Overlay（M）またはツールバーのマーカー表示ボタンで、マーカーの表示を切り替えます
  • Window > Marker Manager（Ctrl+F8）の「色を変更...」で、マーカーの色を変えられます（すべてのマーカーで1色）

まとめて消す

メニュー内容
Edit > Clear Page Markers現在のページのマーカーを消す
Edit > Clear Stage Markers現在のステージのマーカーを消す
Edit > Clear All Markersすべてのマーカーを消す
マーカーはエディタを起動している間だけの作業メモです。ファイルには保存されず、 エディタを終了すると消えます。残しておきたい情報は、ページの Remarks やタグを使ってください。
