ブックマーク

Ver.1.10

ブックマークは、よく見るページへすぐに移動するための目印です。 プロジェクト全体で管理するので、ステージをまたいで移動できます。

ブックマークを付ける・外す

次のいずれかの操作で、現在のページにブックマークを付けます。すでに付いている場合は外れます。

操作内容
Ctrl+B / Edit > Add Bookmark現在のページのブックマークを付ける・外す
マップビューの右クリックメニュー「現在のページをブックマークに追加」／「ブックマークを解除」
Stage Explorer のページの右クリックメニュー「ブックマークを追加」／「ブックマークを削除」

ブックマークの名前（Label）には、最初はページ名が入ります。 ブックマークの追加・削除・編集は Undo（Ctrl+Z）で元に戻せます。

ブックマークの目印

  • Stage Explorer で、ブックマークしたページの名前の後ろに ★ が付きます
  • ブックマークしたページを開いているとき、ページナビバー（ページ番号の表示欄）にブックマークのアイコンが表示されます

Bookmark List で移動する

Window > Bookmark List（F9）で、ブックマークの一覧（Stage / Page / Label）を表示します。

操作内容
行をダブルクリックそのページへ移動
列の見出しをクリックその列で並べ替え
右クリック > Edit名前（Label）と説明（Description）を編集
右クリック > Deleteブックマークを削除

すべてのブックマークを消す場合は Edit > Clear All Bookmarks を使います（確認あり、Undo 可）。

保存

ブックマークは .sseproj に保存され、プロジェクトを開いたときに復元されます。 ステージを削除すると、そのステージのブックマークも一緒に削除されます。 ページを削除した場合、そのページのブックマークは Bookmark List に表示されなくなります。
